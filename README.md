# 🔬 Science Learning Hub

> **Making science easier to understand through interactive and accessible learning.**

Science Learning Hub is an educational platform designed to help students learn science in a more engaging and practical way.

Many scientific concepts can be difficult to understand when they are presented only through textbooks, definitions, or memorization. Science Learning Hub aims to bridge this gap by combining **educational articles, interactive simulations, visual learning, quizzes, and progress tracking** in one platform.

## 🌟 What Problem Does It Solve?

Science education often requires students to connect abstract ideas with real-world phenomena. Without visual or interactive experiences, this can make learning difficult and less engaging.

Science Learning Hub was created to provide a learning environment where students can:

* Explore concepts at their own pace
* Visualize scientific phenomena
* Experiment with interactive simulations
* Learn through structured articles
* Practice their understanding through quizzes
* Track their learning progress

The goal is not simply to help students **remember** information, but to help them **understand** it.

---

## 🚀 Key Features

### 📚 Educational Articles

Provides accessible learning materials covering scientific topics with clear explanations, examples, and supporting visuals.

### 🧪 Interactive Simulations

Allows students to interact with scientific concepts and experiment with different scenarios.

Instead of only reading about how something works, students can explore it themselves and observe the results.

### 🔎 Search & Discovery

Students can easily discover articles, simulations, and other learning materials based on the topics they are interested in.

### 📰 Related Learning

Related articles help students continue exploring a subject and discover connections between different concepts.

### 📝 Interactive Quizzes

Students can test their understanding after learning a topic and identify areas that need more practice.

### 📊 Progress Tracking

Learning progress allows students to monitor their development and encourages them to continue learning.

### 👤 User Profiles

Users have personal profiles where they can manage their account and access their learning experience.

## 📖 Current Learning Content

The platform currently focuses on **physics**, particularly introductory mechanics and motion.

Learning materials include topics such as:

* Fundamentals of motion
* Motion graphs
* Accelerated motion
* Projectile motion
* Visual interpretation of physical phenomena

The content is designed to build understanding progressively, starting from fundamental concepts and moving toward more complex applications.

---

## 🧠 Learning Approach

Science Learning Hub follows a simple learning philosophy:

> **Learn → Visualize → Experiment → Practice → Understand**

The platform combines different forms of learning rather than relying on a single method.

Students can first learn a concept through an article, explore it through a simulation, practice through quizzes, and then track their progress.

## ⚙️ How to Run

The repository contains both the frontend and backend applications:

```text
science-learning-hub
frontend
└── backend
```

### 1. Clone the Repository

```bash
git clone https://github.com/maximilianvincentius/science-learning-hub.git
cd science-learning-hub
```

### 2. Configure Environment Variables

The project requires environment variables for both the frontend and backend.

First, create the frontend environment file in the **project root** based on the provided example:

```text
.env.example → .env
```

Then configure the backend environment variables:

```text
backend/.env.example → backend/.env
```

Fill in the required values according to the provided `.env.example` files.

### 3. Install Dependencies

Install dependencies for both applications:

```bash
cd frontend
npm install

cd ../backend
npm install
```

### 4. Start the Applications

Start the backend:

```bash
cd backend
npm run dev
```

Then, in another terminal, start the frontend:

```bash
cd frontend
npm run dev
```

The frontend will provide the web interface, while the backend provides the API and application services.
